# Endo's Blog

This repository hosts a simple personal website you can customize.

## Getting Started

Open `index.html` in your browser to view the site. The homepage uses images from Unsplash as placeholders.

To personalize with your own photos, replace the image URLs in `index.html` with paths to your images or place your files in the `images/` folder and update the HTML accordingly.

The layout and fonts are defined in `css/style.css`. Feel free to adjust the styling to match your taste.
